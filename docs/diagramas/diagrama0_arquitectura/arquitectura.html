Diagrama de arquitectura distribuida

Plataforma E-Commerce Distribuida NodoTec, Tienda de Electrónica y Tecnología. Proyecto Final No. 2, Desarrollo de Aplicaciones Web, UMG 2026.

Cómo leer el diagrama

  • El recuadro gris es el VPS; el recuadro azul discontinuo, la red interna de Docker. Solo el API Gateway publica puertos (80 y 443).
  • Las flechas negras son peticiones del usuario por HTTPS. El Gateway enruta /api/auth/, /api/catalogo/, /api/pedidos y /api/pagos/; notificaciones-service no tiene ruta pública.
  • Las flechas moradas numeradas son llamadas internas con el JWT del usuario; no pasan por el Gateway.
  • Las flechas verdes son accesos a datos: escrituras al Master, lecturas de catálogo y reportes al Slave, caché y tokens revocados en Redis. La línea discontinua es la replicación.
  • Las flechas ámbar son llamadas HTTPS a las APIs externas; las claves secretas solo están en el .env del servidor.
