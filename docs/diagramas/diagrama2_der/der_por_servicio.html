Diagrama entidad-relación por microservicio

Plataforma E-Commerce Distribuida, Tienda de Electrónica y Tecnología. Proyecto Final No. 2, Desarrollo de Aplicaciones Web, UMG 2026.

Cómo leer el diagrama

  • Cada recuadro de color es una base de datos independiente, propiedad de un solo servicio.
  • Las líneas dentro de un recuadro son relaciones entre tablas de la misma base de datos.
  • La línea punteada morada cruza de una base de datos a otra: es una referencia lógica. No existe llave foránea; el dato se consulta mediante la API del otro servicio.

Puntos pendientes de confirmar con el desarrollador

  • Tipos de datos y restricciones de todos los campos (por ejemplo, si email es único).
  • Campos de las tablas categorias, clientes, detalle_pedidos y direcciones.
  • Campo de productos que la relaciona con categorias (el enunciado permite filtrar por categoría, pero no lista ese campo).
  • Si direcciones se relaciona con clientes o con pedidos.
  • Cómo se vincula clientes (pedidos_db) con usuarios (auth_db).
  • Cómo detalle_pedidos identifica el producto de catálogo y si guarda el precio al momento de la compra.
  • Dónde se guarda la referencia de PayPal: el enunciado solo define referencia_stripe.
