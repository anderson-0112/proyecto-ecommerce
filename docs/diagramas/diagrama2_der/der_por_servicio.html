Diagrama entidad-relación por microservicio

Plataforma E-Commerce Distribuida NodoTec, Tienda de Electrónica y Tecnología. Proyecto Final No. 2, Desarrollo de Aplicaciones Web, UMG 2026.

Cómo leer el diagrama

  • Cada recuadro discontinuo es una base de datos independiente, propiedad de un solo servicio y con su propio usuario de MariaDB.
  • Las líneas azules son llaves foráneas (relación 1 a N) dentro de la misma base.
  • Los campos marcados RL (en morado) son referencias lógicas a otra base: no tienen llave foránea y se validan mediante la API del otro servicio.

Decisiones aplicadas

  • Llaves primarias INT UNSIGNED AUTO_INCREMENT; importes DECIMAL(10,2); email y referencias de pago únicos.
  • Campos de categorias, clientes, detalle_pedidos y direcciones definidos (D5); productos.categoria_id es llave foránea hacia categorias.
  • direcciones se relaciona con clientes; clientes.id_usuario corresponde a usuarios.id de auth_db (D6).
  • detalle_pedidos guarda el id, el nombre y el precio del producto al momento de la compra.
  • pagos agrega referencia_paypal junto a referencia_stripe (D4).
