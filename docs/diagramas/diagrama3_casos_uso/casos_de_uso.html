Diagrama de casos de uso

Plataforma E-Commerce Distribuida NodoTec, Tienda de Electrónica y Tecnología. Proyecto Final No. 2, Desarrollo de Aplicaciones Web, UMG 2026.

Cómo leer el diagrama

  • Actores a la izquierda: personas que usan la plataforma. Cliente hereda todo lo que puede hacer el Visitante.
  • Recuadros a la derecha: servicios web externos que participan en un caso de uso.
  • «include»: el caso base siempre ejecuta el incluido (realizar un pedido implica pagarlo; el dashboard siempre muestra el clima).
  • «extend»: comportamiento opcional que amplía el caso base (comunicarse con el cliente al gestionar un pedido).

Decisiones aplicadas

  • Se mantiene el actor Visitante, que consulta el catálogo sin registrarse (A5).
  • Comunicarse con el cliente: enlace mailto: con asunto prellenado en el detalle del pedido (D12).
  • El estado de un pedido lo consultan el cliente dueño y el administrador (D16).
  • La cuenta de administrador es un usuario de prueba creado por db/init-master.sql; el registro público solo crea clientes (D17).
  • El código QR se genera cuando el pedido pasa a pagado (D11).
