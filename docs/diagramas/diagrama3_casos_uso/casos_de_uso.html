Diagrama de casos de uso

Plataforma E-Commerce Distribuida, Tienda de Electrónica y Tecnología. Proyecto Final No. 2, Desarrollo de Aplicaciones Web, UMG 2026.

Cómo leer el diagrama

  • Actores a la izquierda: personas que usan la plataforma. Cliente hereda todo lo que puede hacer el Visitante.
  • Recuadros a la derecha: servicios web externos que participan en un caso de uso.
  • «include»: el caso base siempre ejecuta el incluido (realizar un pedido implica pagarlo; el dashboard siempre muestra el clima).
  • «extend»: comportamiento opcional que amplía el caso base (comunicarse con el cliente al gestionar un pedido).

Puntos pendientes de confirmar con el desarrollador

  • Si se mantiene el actor Visitante (el enunciado exige ver el catálogo sin registro, pero solo define los roles cliente y admin).
  • Cómo se implementa "comunicarse con el cliente" (enunciado, sección 6.5): correo, teléfono visible u otro mecanismo.
  • Quién puede consultar el estado de un pedido: solo el cliente dueño, el administrador o ambos.
  • Cómo se crea la cuenta de administrador (el registro público es solo para clientes).
  • En qué momento se genera el código QR del pedido.
